# Bonetti Store - Guia de Conexão entre o Banco SQL do Supabase e o GitHub

Este repositório contém o site da **Bonetti Store** integrado com o banco de dados PostgreSQL/SQL do **Supabase**.

---

## 🚀 Passo a Passo Completo para Conectar o Supabase ao Repositório GitHub

### 1. Criar um Projeto no Supabase
1. Acesse [supabase.com](https://supabase.com/) e faça login ou crie uma conta gratuita.
2. Clique em **"New Project"** (Novo Projeto).
3. Preencha o nome do projeto (ex: `Bonetti Store`), escolha uma senha forte para o banco de dados e selecione a região mais próxima (ex: `South America (São Paulo)`).
4. Aguarde a criação do projeto ser concluída.

---

### 2. Executar o Script SQL para Criar as Tabelas
1. No painel do seu projeto no Supabase, acesse a aba **"SQL Editor"** no menu lateral esquerdo.
2. Clique em **"New Query"** (Nova Consulta).
3. Abra o arquivo `supabase_setup.sql` deste repositório, copie todo o seu conteúdo e cole no SQL Editor do Supabase:

```sql
-- Criacao da tabela de produtos
CREATE TABLE IF NOT EXISTS public.products (
    id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    name VARCHAR(255) NOT NULL,
    brand VARCHAR(100) NOT NULL,
    price NUMERIC(10, 2) NOT NULL,
    image_url TEXT,
    created_at TIMESTAMP WITH TIME ZONE DEFAULT timezone('utc'::text, now()) NOT NULL
);

-- Habilitar Row Level Security (RLS)
ALTER TABLE public.products ENABLE ROW LEVEL SECURITY;

-- Criar politica de leitura publica
CREATE POLICY "Permitir leitura publica dos produtos"
ON public.products
FOR SELECT
USING (true);

-- Inserir produtos iniciais
INSERT INTO public.products (name, brand, price, image_url) VALUES

('Adidas Samba OG White', 'Adidas', 699.90, 'https://images.unsplash.com/photo-1584735935682-2f2b69dff9d2?w=600'),
('Puma Suede Classic', 'Puma', 449.90, 'https://images.unsplash.com/photo-1608231387042-66d1773070a5?w=600'),
('Vans Old Skool Black/White', 'Vans', 399.90, 'https://images.unsplash.com/photo-1525966222134-fcfa99b8ae77?w=600');
```

4. Clique no botão **"Run"** (ou aperte `Ctrl + Enter`) para executar o script. Isso criará a tabela `products` e cadastrará os produtos de exemplo.

---

### 3. Obter as Credenciais de API do Supabase
1. No menu lateral do Supabase, clique em ⚙️ **Project Settings** > **API**.
2. Copie os seguintes valores:
   - **Project URL** (ex: `https://xxxx.supabase.co`)
   - **Project API Keys** -> `anon` / `public` (Chave pública do projeto)

---

### 4. Configurar as Credenciais no Repositório
No arquivo `js/supabaseClient.js`, substitua os valores padrão pelas suas credenciais obtidas no passo anterior:

```javascript
const SUPABASE_URL = 'https://seu-projeto.supabase.co';
const SUPABASE_ANON_KEY = 'sua-chave-anon-aqui';
```

---

### 5. Ativar o GitHub Pages para Publicar o Site
1. Acesse o seu repositório no GitHub: `https://github.com/l1pehz/l1pehz.github.io`.
2. Vá em **Settings** > **Pages** no menu superior.
3. Em **Source**, selecione a branch `main` (ou `master`) e a pasta `/ (root)`.
4. Clique em **Save**.
5. Em instantes, o seu site estará no ar conectando e carregando dados dinamicamente do banco de dados SQL do Supabase!

---

## 📁 Estrutura de Arquivos do Repositório

- `index.html`: Página principal acessada pelo GitHub Pages.
- `site pw bonneti store.html`: Cópia / versão original da loja atualizada com a integração Supabase.
- `supabase_setup.sql`: Script SQL para criar o banco de dados e tabela de produtos no Supabase.
- `js/supabaseClient.js`: Módulo JavaScript que faz a comunicação entre o site front-end e a API do Supabase.
